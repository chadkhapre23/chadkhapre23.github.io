🎮 pixel-faceplate - Control Your Faceplate, Skip the Bloat

pixel-faceplate is a simple add-on for your Steam Machine that lets you take charge of the JSAUX PIXEL faceplate directly from Steam. No separate vendor program, no background services, no extra accounts. Download it, switch it on, and your faceplate is yours to control.

Download pixel-faceplate Free and open source. Works alongside Decky Loader.

✨ What This Plugin Does

The JSAUX PIXEL faceplate is a great-looking piece of hardware, but the usual way to configure it means installing a whole separate program from the manufacturer. That program can be heavy, it can demand permissions you may not want to give, and it can get in the way of the rest of your setup.

pixel-faceplate replaces all of that. It is a plugin that lives inside Decky Loader, the popular add-on manager for Steam Machine devices. Once it is installed, the plugin gives you a clean panel right in the Steam interface where you can adjust how your faceplate behaves. You never have to leave Steam to make a change.

Because the plugin runs inside the tools you already use, it stays out of the way when you are not using it. There is nothing extra running in the background and nothing extra to log in to.

🎯 Key Features

🧩 No Vendor Software Required

The single biggest reason people look for an alternative is the bundled manufacturer utility. This plugin removes that dependency completely. You get full control without a second company's installer touching your device.

🖥️ Lives Inside Your Steam Interface

All of your controls appear as a panel in Decky Loader. That means no switching between windows, no alt-tabbing, and no separate desktop app to keep track of.

⚡ Light and Quiet

The plugin is intentionally small. It does one job and it does it without hogging memory or battery life on your Steam Machine.

🔧 Set It and Forget It

Your preferences are remembered between sessions, so you do not have to reapply your settings every time you boot up. Configure it once and carry on playing.

📖 Open and Inspectable

Everything is published openly on GitHub. If you are curious about what the plugin does under the hood, you can read through it yourself or ask questions in the project's discussion area.

🚀 Getting Started

Getting the plugin onto your machine takes just a few minutes. You do not need to know how to program, and you do not need any special tools beyond a browser and a file explorer.

Step 1 — Visit the download page. Open the official project page using the button below. Visit this link to download the application.

Visit the pixel-faceplate page

Step 2 — Save the download. On the project page, locate the download area. Your browser will ask where to save the file. The Downloads folder is a perfectly fine place to keep it.

Step 3 — Make sure Decky Loader is ready. pixel-faceplate runs as part of Decky Loader. If you have not set Decky Loader up yet, do that first — it is a one-time step that many Steam Machine owners have already completed. Once Decky Loader is running, adding a new plugin takes only a couple of clicks.

Step 4 — Install the plugin. With Decky Loader open, use its plugin installation option and point it at the file you downloaded in Step 2. Follow the on-screen prompt to finish. When it completes, pixel-faceplate will appear in your Decky plugin list.

Step 5 — Turn it on. Open the Decky panel and enable pixel-faceplate. The configuration screen will be ready for you right away.

🕹️ Using Your PIXEL Faceplate

Once the plugin is active, you can open its panel at any time from the Decky menu. Everything is arranged on a single screen so you can see what you are changing without digging through sub-menus.

  • Open the panel: Bring up Decky Loader and select pixel-faceplate from your plugin list.
  • Adjust your settings: Make your changes using the on-screen controls. Each change takes effect as you make it.
  • Save and close: Your selections are stored automatically, so you can simply back out when you are finished.
  • Return anytime: The plugin stays available on your device. Open it again whenever you want to tweak something.

If you ever want to start fresh, you can reset your preferences from within the panel and begin again with the default configuration.

🛠️ Troubleshooting Tips

Most issues have a simple fix. Try these in order:

  1. The plugin does not appear in my list. Restart your device and open Decky Loader again. Plugin lists sometimes need a refresh before a newly installed item shows up.
  2. The download did not finish. Try the download again from the project page and make sure the file finished saving before you install it.
  3. My settings are not being remembered. Confirm that you are closing the panel normally rather than force-quitting the Steam interface while it is open.
  4. Something looks broken after a Steam update. System updates occasionally shift things around. Check the project page for the newest version, which usually addresses this.
  5. The panel opens but feels unresponsive. Give it a moment after the first launch — the very first load can take slightly longer than later ones.

❓ Frequently Asked Questions

Do I need to install the manufacturer's software as well?

No. That is the entire point of this project. pixel-faceplate is built so you can skip the vendor utility completely.

Is this free?

Yes. The project is free and openly published.

Will this work on my device?

pixel-faceplate is designed for Steam Machine devices running Decky Loader with the JSAUX PIXEL faceplate attached. If that describes your setup, you are in the right place.

Do I need to be technical to install it?

No. If you can download a file and click through a couple of on-screen prompts, you can install this plugin.

Will it slow down my device?

The plugin is deliberately lightweight and only does work while its panel is open. Most people never notice it running.

How do I remove it later?

Open Decky Loader, find pixel-faceplate in your installed plugins, and choose the uninstall option. The plugin is removed cleanly and leaves nothing behind.
